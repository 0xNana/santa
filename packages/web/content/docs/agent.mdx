---
title: CLI
description: Send stock gifts to loved ones from the command line.
---

The Santa CLI uses a dedicated test wallet on Robinhood Chain Testnet. Put `SANTA_AGENT_PRIVATE_KEY`, `SANTA_VAULT_ADDRESS`, `SANTA_PUBLIC_ORIGIN`, and optionally `ROBINHOOD_RPC_URL` in the repo-root `.env`. It does not read the deployer or relayer key as the sending wallet.

```sh
npm run santa -- status
npm run santa -- gift TSLA 5 --note "For your next chapter. With love." --days 30
npm run santa -- gift AMD 10 --yes
```

The quantity is stock token units, not dollars. Your wallet must already hold the listed stock token and test ETH. The CLI asks for confirmation unless `--yes` is supplied. It builds the exact approval locally, seals the gift, and saves its private link under `gifts/46630/<vault>/`. Link files have permission 0600.

A pending key is written before a gift can be submitted. If a send is interrupted, `status` looks for its gift and saves the recovered link. Keep pending files until recovery completes; never share or commit them. Links and keys are not printed in terminal output.
