## Run locally

```sh
npm ci
cp .env.example .env
npm run dev --workspace=@santa/web
```

Set `NEXT_PUBLIC_PRIVY_APP_ID`, both vault settings, `RELAYER_PRIVATE_KEY`, and `SANTA_PUBLIC_ORIGIN`. Use shared Upstash credentials for a hosted server, or `SANTA_ALLOW_MEMORY_STORE=1` locally. Local requests use `SANTA_DEV_COUNTRY` (for example GH).

## Deploy a test vault

```sh
cd packages/contracts
./install-deps.sh
./deploy.sh testnet
```

Set `DEPLOYER_PRIVATE_KEY` and a separate `SANTA_RELAYER_ADDRESS` first. The deployer must have test ETH. Set `SANTA_STOCK_ADDRESSES` to the testnet ERC-20s to list. The script creates SantaVault. Set `SANTA_VAULT_ADDRESS` and `NEXT_PUBLIC_SANTA_VAULT_ADDRESS` to the printed vault address, then rebuild the web app. They must match.

## Get stocks on testnet

Use the [Robinhood Chain testnet faucet](https://faucet.testnet.chain.robinhood.com/) to obtain test ETH and listed stock tokens. The current vault lists TSLA, AMD, AMZN, NFLX and PLTR.

## Send and receive

Open `/send`, connect your wallet, choose a stock, choose 1 to 100 units, and add a note. Approve exactly that quantity to the vault, then seal the gift. Copy its link privately. The recipient signs in, confirms the declaration, and opens it. No wrapping payment is required.
